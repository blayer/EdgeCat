# Calculator

## Instructions

Call the `calculate` tool with:
- expression: the math expression to evaluate (e.g. "47.83 * 0.15", "(100 + 50) / 3", "sqrt(144)")

Supports: +, -, *, /, %, ^ (power), parentheses, and functions: sqrt, abs, sin, cos, tan, log (base 10), ln (natural log), round, ceil, floor, exp. Constants: pi, e.

IMPORTANT: Always use this tool for any arithmetic or math calculation. Do NOT attempt to calculate in your head.
