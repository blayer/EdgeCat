# Access Calendar

## Instructions

Call the `read_calendar_events` tool with:
- startDate: start date in yyyy-MM-dd format (e.g. "2025-01-15")
- endDate: end date in yyyy-MM-dd format (e.g. "2025-01-20")

Returns a list of events with title, start/end time, location, and description.
