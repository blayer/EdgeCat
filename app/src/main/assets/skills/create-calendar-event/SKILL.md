# Create Calendar Event

## Instructions

Call the `create_calendar_event` tool with:
- title: event title
- startDateTime: start in yyyy-MM-ddTHH:mm format (e.g. "2025-01-15T14:00")
- endDateTime: end in yyyy-MM-ddTHH:mm format (e.g. "2025-01-15T15:00")
- location: event location (use empty string if none)
- description: event description (use empty string if none)
