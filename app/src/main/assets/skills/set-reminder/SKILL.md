# Set Reminder

## Instructions

Call the `set_reminder` tool with:
- title: reminder title (e.g. "Pick up groceries")
- dateTime: date and time in yyyy-MM-ddTHH:mm format (e.g. "2025-01-15T09:00")
- minutesBefore: minutes before the time to show the alert (e.g. "10")

Creates a calendar event with an alert notification.
